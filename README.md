# William 🤖

A chat website where you talk to **William**, an AI buddy. Built by Naz.

Live: https://tcjvm24djr-blip.github.io/william/

- Change William's personality: edit `SYSTEM_PROMPT` at the top of `script.js`.
- Colors/themes: `styles.css` (look for `[data-theme=...]`).
- AI: free Pollinations text API (no key). The free version allows about 1 reply every 30 seconds per device, so William may pause to "catch his breath".
